## 🚀 Quick Start & Package Conventions

### Package Naming Standard
Every module and source code file in this repository strictly adheres to standard Java reverse-domain naming under the **`decodewithpriyo`** namespace:

```
com.decodewithpriyo.<module_topic>
```

For example:
- `com.decodewithpriyo.basics`
- `com.decodewithpriyo.oop`
- `com.decodewithpriyo.collections`
- `com.decodewithpriyo.spring`

### Directory Layout
Each module directory follows a clean standard layout:
```text
<module-name>/
├── README.md                          # Detailed topic documentation, notes, and exercises
└── src/
    └── com/
        └── decodewithpriyo/
            └── <module_topic>/
                └── Main.java          # Entry point and topic demonstration code
```

### Compiling and Running from the Command Line
You can compile and run any module from its root directory or from the workspace root:

```bash
# Navigate to a module directory
cd 01-java-basics

# Compile using javac
javac -d out src/com/decodewithpriyo/basics/Main.java

# Run using java
java -cp out com.decodewithpriyo.basics.Main
```

### IDE Setup
- **IntelliJ IDEA**: Open the root `Java` folder as a project. Each module's `src` directory can be marked as a **Sources Root** (`Right-click src -> Mark Directory as -> Sources Root`).
- **VS Code**: Install the *Extension Pack for Java*. Open the root folder; VS Code will automatically detect the source packages under `src/com/decodewithpriyo/...`.
